# Age, risk, and HIV prevention: PrEP preferences among female sex workers in South Africa
This repository contains analysis code for a study of socio-behavioral and structural correlates of PrEP modality preferences among female sex workers (FSW) in South Africa.
## Current Status: Manuscript prepared and awaiting review
## Study Overview:
FSW across two districts in South Africa were recruited to complete a structured survey. 
The sample included 400 FSW (170 younger, <25 years; 230 older, ≥25 years). 
The analysis was guided by the Modified Social Ecological Model (MSEM).
## Methods Overview:
- Socio-behavioral and structural correlates of PrEP modality preferences were assessed using Chi-square and t-tests
- Modified Poisson regression models with a robust variance estimator were used to estimate unadjusted and adjusted prevalence ratios (PR) and 95% confidence intervals (CI)
## Software:
- Stata 18 (StataCorp, College Station, TX)
## Repository Files:
-Descriptive analysis code
-Regression analysis code
## Data Availability
Participant-level data used in this analysis are not publicly available due to the sensitive nature of the data and participant confidentiality.
Inquiries regarding the data may be directed to Dr. Katherine Rucinski (rucinski@jhu.edu).
